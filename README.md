# Exercícios Java ☕

Repositório com exercícios desenvolvidos durante meus estudos de **Java e Lógica de Programação**.

## Exercícios

1. **Pedido de café** — variáveis e cálculo do valor total.
2. **Validador de senha** — validação de tamanho, letra maiúscula e número.
3. **Verificação de maiúscula** — uso de `for` e `Character.isUpperCase`.
4. **Desconto de produto** — estrutura condicional e cálculo de desconto.
5. **Desconto de produto (cópia do exercício)** — prática de condicionais.
6. **Calculadora** — soma, subtração, multiplicação e divisão com `switch`.
7. **Boletim escolar** — cálculo de média e situação do aluno.
8. **Status da nota** — aprovado, recuperação ou reprovado.
9. **Tabuada** — repetição com `for`.
10. **Classificação de eleitor** — condicionais com base na idade.
11. **Estatísticas de números** — quantidade, maior, menor e média usando `while`.

## Tecnologias

- Java
- Lógica de Programação
- Estruturas condicionais
- Laços de repetição
- Scanner

## Organização

Cada exercício está em uma pasta própria e possui seu arquivo `Main.java`.
