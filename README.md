# Exercícios Java ☕

Repositório com exercícios desenvolvidos durante meus estudos de **Java e Lógica de Programação**.

## Conteúdos praticados

- Variáveis e cálculos
- Entrada de dados com `Scanner`
- Estruturas condicionais (`if`, `else if`, `else`)
- `switch`
- Laços `for`, `while` e `do-while`
- `break` e `continue`
- Contagens, médias e validações

## Exercícios

O repositório possui exercícios organizados em pastas individuais, cada uma contendo seu próprio arquivo `Main.java`.

Entre os exercícios estão calculadora, boletim escolar, tabuada, classificação de eleitor, estatísticas de números, números pares, contagem regressiva e exemplos práticos de `while`, `do-while`, `break` e `continue`.
